INTERACTIVE SYSTEM ARCHITECTURE & DEMO

高压竞技战术推演与心理干预系统 · 架构与落地细节

针对通用大模型在体育推演中“泛泛而谈、缺乏落地力学依据”的缺陷，独立设计的双流解耦工程方案。

轨道一：战术对抗分析流（客观力学）

结构化胶皮物理特性表（长胶拱/磕/刮、生胶弹击、反胶强烈摩擦下旋），建立回球旋转反转对照矩阵。强制系统输出：

  • 精确落点区域（正手大角度浅落点 / 追身中路）
  • 击球板形与发力角度（前倾 35° / 摩擦前上沿）
  • 接发球二板预判套路（摆短转劈长衔接）

轨道二：身心调控干预流（抗压锚定）

避免单模型在计算力学时混入过多主观安慰剂空话。将十年赛场冠军经验总结为三步标准化降压动作：

  • 生理性叹息呼吸（两次深吸 + 一次长吐骤降心率）
  • 球台白线与乒乓球印字视线锚定法（夺回注意力）
  • 高压决胜局认知负荷剥离（只看下一次触球动向）

ENTERPRISE RAG ARCHITECTURE & BAD CASE AUDIT

垂直场景知识库重构与问答检索治理方案

在安溪皇家茶业数字化运营中的真实实战治理过程。

1. 机械切片导致的语义断裂修复

原系统按固定字数切块，导致冲泡水温、浸润时间与茶品编号被硬生生切在两个 Chunk，召回率骤降。改用“大段背景携带核心参数”的分块策略，保留完整的上下文语义关联。

2. 关键词与向量混合加权匹配

特定茶叶 SKU 与品类代号在纯语义向量中余弦相似度容易被稀释，导致搜漏。通过搭建关键词精确过滤与语义余弦相似度双路加权融合，彻底消除了料号遗漏的 Bad Case。

3. 边界约束与提示词防乱推荐

在 System Prompt 中严控 Few-shot 与 Negative Constraints（负向约束），未召回到精准工艺参数时明确拒绝幻觉编造，引导转人工或提示确认编号。
